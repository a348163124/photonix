# LumaForge

Codename: `x-image`

## Product Name

`LumaForge`

## Naming Idea

- `Luma` represents light, tone, atmosphere, and photographic luminance.
- `Forge` represents reconstruction, transformation, and AI-assisted creation.
- Together, `LumaForge` feels like a tool that reshapes light and image structure with precision.

## Positioning

LumaForge is a Windows-first AI photo editing desktop application built around `gpt-image-2`, focused on large-image local workflows, prompt-driven editing, and mask-based regional repair.
